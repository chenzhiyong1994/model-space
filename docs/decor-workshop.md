# 装潢与收藏玩法

装潢工坊把展厅布置成可以停留的小收藏馆。当前包含 27 件真实 CC0 模型和 7 件原创布置小物，既能一键搭配，也能逐件调整。搭配完成后，可以[进入漫游](immersive-gallery.md)，从第一人称视角欣赏自己的收藏。

## 先布置一个角落

切换到想装潢的房间，在左侧点击「装潢」。点击任意套装，应用会在房间周边寻找空闲角落，添加六件独立物体并设置搭配的地面。

| 套装 | 六件搭配 | 地面 |
| --- | --- | --- |
| 精品开店 | 收藏小铺柜台、小店招牌、拱门屏风、收藏展海报、斑叶陶盆绿植、现代细身陶瓶 | 浅色水磨石 |
| 绿意阅读 | 编织地毯、胡桃木皮革躺椅、大理石圆茶几、斑叶陶盆绿植、收藏展海报、白瓷花口瓶 | 暖木地板 |
| 创作咖啡 | 编织地毯、复古咖啡推车、北欧皮革扶手椅、现代长茶几、古董油灯、斑纹多肉 | 暖木地板 |
| 玩趣收藏 | 精品陈列桌、扭蛋机、小店招牌、收藏展海报、花园长盆、黄铜小花瓶 | 浅色水磨石 |

一次布置可以用 Ctrl+Z 整体撤销，Ctrl+Shift+Z 重做。当前房间还保留该套装的标记物体时，重复点击同一套装不会堆出重复角落；如果想安排更多座椅或盆栽，从下方单件素材添加，或选中已有物体后 Ctrl+D 复制。

已有陈列过满时会提示没有足够空闲角落。可以先整理物体，或点击画面上方「编辑房间尺寸」扩建，再布置整套；也可以逐件添加。宽度最多 120 m、进深最多 100 m。套装不会自动搬动既有展品。

## 自由调整家具和地面

装潢工坊下方包含「精挑细选 · 真实材质」和「店主的布置小物」。点击卡片即可添加，随后可移动、旋转、缩放、复制、锁定或移至其他房间。G / R / S 切换操作柄，F 聚焦选中物体。

家具与桌面上的摆件都是独立物体：移动茶几、柜台或展示桌后，再调整其上的花器和展品位置。真实模型保持原始 PBR 色彩；原创布置小物可在属性面板调整材质色彩。

按 Esc 取消物体选择，右侧「脚下的质感」可选画廊原色、暖木地板、浅色水磨石或灰蓝石砖。更换地面可撤销，刷新和完整备份都会保存该选择。

## 免费扭一份小珍藏

选中房间中的任意扭蛋机，在右侧点击「免费扭一下」。新收藏出现在机器附近的可用位置，弹窗显示结果；点击「去摆放它」安排陈列，也可以「再扭一次」。机器周围没有空位时会提示挪开附近物品或移动机器。

六款收藏是苔绿小猫、蜂蜜小狗、玫瑰小兔、可可小熊、阳光小鸭和丁香小精灵。可以抽到重复款，每件都能独立摆放、复制和移至其他房间。一次抽取对应一步历史，Ctrl+Z 可以撤销。

装潢工坊的「小小惊喜图鉴」统计所有房间实际持有的扭蛋珍藏。收藏同款多件只点亮一个印记；删除最后一件该款收藏后，印记会消失，撤销删除则恢复。普通同类素材不自动计为扭蛋收藏。目前没有货币、访客或营业收益，玩法围绕布展、搭配与收集展开。

## 保存和继续布展

布局自动保存在当前浏览器。通过顶部「导出空间」保存完整 `.modelspace` 备份，包含房间布局、地面、套装和收藏信息以及导入模型原文件；精选装潢资源由应用本地文件提供。换浏览器时，在当前版本应用中恢复备份即可继续布置。

公开版本从五个内置示例展厅开始，自己的布置通过备份迁移。恢复会替换目标浏览器当前项目，操作前先导出需要保留的作品；完整说明见[数据与备份](user-guide.md#保存备份与恢复)。网络素材作者、CC0 许可与加工记录见[素材来源](asset-sources.md)。
