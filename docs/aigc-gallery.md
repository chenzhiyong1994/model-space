# GLB 素材接入

无论模型来自手工建模、扫描还是 AIGC，藏境都通过同一个 GLB 入口导入。公开版本从五个内置示例展厅开始；自行导入的模型和个人布展备份由使用者保存在自己的浏览器或文件中。

## 准备模型

在 Blender 或其他建模工具中导出 **glTF 2.0 Binary（`.glb`）**。纹理图片与几何缓冲区都应嵌入文件，单个模型最大 50 MiB。应用会校验 GLB 结构与资源引用。

`.blend`、`.fbx`、`.obj` 和依赖外部文件的 `.gltf` 需要先转换。导出时关闭 Draco、Meshopt 与 KTX2 压缩；应用没有随附这些解码器。

对于包含文字、曲线、修改器、驱动或程序材质的作品，先检查导出效果：需要的几何应转换或求值为网格，程序纹理可烘焙为图片，并使用可导出的 PBR 材质。灯光、相机和空控制器不能代替实体模型。当前应用不播放 Blender 时间线或模型动画。

## 导入和布展

1. 在应用中打开导入入口，选择 GLB。
2. 导入成功后，从模型库点击卡片放置。模型原文件写入 IndexedDB，同一资源可生成多个独立实例。
3. 首次放置时，模型按最长边 1.2 m 归一化，X/Z 居中、底部贴地。再通过属性或三维操作柄调整位置、旋转与缩放。
4. 使用 F 聚焦近看，检查材质、正反面、尺寸和陈列高度。
5. 导出完整 `.modelspace`，同时备份布局与模型原文件。

场景单位为米、Y 向上。展台和模型是独立实例，移动展架不会自动携带展品。常用层板高度见[使用指南](user-guide.md#选择与摆放)。

## 批量素材的整理建议

为模型使用清楚的名称；几何相同、仅重复摆放的内容可以导入一次，从模型库重复放置。把相关模型布置到同一展厅，按体量安排落地陈列或分层架，预留行走通道。

大量高面数模型和大尺寸纹理会增加下载、内存与绘制开销。先用少量素材验证效果，再逐步扩充；数据上限不代表设备能够流畅渲染所有组合。藏境不代替建模软件中的减面、贴图压缩与模型修复流程。

## 分享作品

用「导出空间」生成完整备份；接收方在当前应用版本中恢复即可读取房间与导入模型。恢复会替换接收方当前空间，应先保存自己的备份。

分享备份或向仓库贡献素材前，请确认具备相应的再分发权限，并保留来源和许可信息。项目内置第三方素材的示例记录见[素材来源](asset-sources.md)；它们的 CC0 许可不会自动适用于自行导入的模型。
