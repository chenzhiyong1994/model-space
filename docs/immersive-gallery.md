# 沉浸漫游

布置完成后，点击画面右上「漫游」走进自己的展厅。素材库、属性面板、编辑工具与底部房间栏收起，房间补齐四面墙，进入全画面游览。

## 行走与环顾

| 操作 | 输入 |
| --- | --- |
| 前后左右移动 | WASD 或方向键 |
| 加速 | 按住 Shift |
| 环顾 | 按住画面拖动 |
| 退出漫游 | Esc 或「返回布置」 |
| 切换展厅 | 右上展馆选择器 |

支持鼠标锁定的前台浏览器也可以点击画面直接环顾。浏览器不允许锁定时，先点击画布获得焦点，再用键盘移动和拖动环顾。第一人称游览主要面向桌面键鼠。

## 碰撞与通路

行走根据模型实际世界包围盒的水平范围避开家具、展柜和落地展品，碰到边缘时可以沿边滑动。地毯和低于 0.12 m 的铺地装饰可直接走过。

实现采用身体半径 0.24 m 的保守包围盒导航，小步进减少加速穿过薄物体的情况；它不是逐三角形物理模拟。细腿桌、凹形模型等也可能按完整包围盒阻挡。布展时留出连贯、足够宽的通道，更便于近距离观看。

模型尚未完成加载，或新布置占用导览位置时，应用会寻找附近可以站立的位置。放大房间不会同步移动已有展品；缩小房间也不会删除墙外物体。

## 导览观察点

若房间带有导览数据，左下角会显示观察点与前后切换按钮。选择观察点只改变相机；手动走动后进入「自由行走」，可以随时再选一个观察点。跨馆切换会保持漫游状态，从新馆入口开始。

新建房间与默认示例可以直接自由漫游。当前没有可视化导览点编辑器；开发者可在经过校验的房间数据中配置 `Room.tour`，每馆最多 12 点：

```ts
{
  id: 'entrance',
  title: '从这里开始',
  description: '沿中央通道欣赏两侧陈列',
  position: [0, 1.68, 4],
  yaw: 0
}
```

`position` 单位为米，相机眼高为 1.68 m；`yaw` 使用 Three.js Euler Y，0 面向 -Z。配置必须通过 `validateProject`。房间缩小时，已有观察点会被限制在新的边界内，展品仍保留原位置。

装潢库中的「游览导览牌」是一件独立物体。重命名时使用 `·` 分隔主副标题，牌面会同步显示；它不会自动创建相机观察点。

## 适合近看的收藏

装潢库随附复古旁轴相机、电影摄影机、显微镜、怀表、望远镜、百科全书、笔记簿、青铜雕塑、古典头像、蕨叶与旅行箱等精细模型。它们来自 Poly Haven 的 CC0 资源，以 GLB、纹理和自行渲染的缩略图随项目提供。

小型相机、怀表适合放在展台上，苔石组合适合整体缩小后作为园景。作者、许可、原始尺寸与加工记录见[素材来源](asset-sources.md)。

复杂几何、透明玻璃和大量重复物体可能增加绘制开销。实际流畅度取决于场景密度和显卡；项目不把数据容量上限作为性能保证。

保存、迁移和恢复自己的展厅，见[使用指南](user-guide.md#保存备份与恢复)。
