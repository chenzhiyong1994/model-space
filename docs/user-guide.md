## 本地启动与停止

需要 Node.js 22.12+。依赖由 `package-lock.json` 锁定，安装在本项目的 `node_modules`。

```bash
npm ci
npm run dev
```

访问 `http://127.0.0.1:5188/`。服务固定使用此地址和端口；切换到 `localhost`、其他端口或在线站点会使用另一份浏览器存储。

Windows 可以双击仓库中的 `启动藏境.cmd`。启动器检查依赖和端口，后台启动服务并打开浏览器；再次启动会复用同一项目服务。关闭浏览器不会停止服务，在 PowerShell 中运行 `./Stop-ModelSpace.ps1` 停止由启动器启动的进程。手动通过 `npm run dev` 启动时，在对应终端按 Ctrl+C 停止。

```bash
npm test
npm run build
npm run preview
```

`preview` 需要已有 `dist`，并使用同一端口。先停止开发服务，再预览生产构建。

## 管理展厅

新浏览器从五个示例开始：造物展厅、形态实验室、灵感储藏室、萌物收藏馆、串珠工坊。底部房间栏可切换、新建、重命名或删除展厅；新建展厅为空房间。房间支持三种空间氛围。

「同步示例展厅」会补齐缺失的示例，并重置同名示例中的布置，确认窗口会说明覆盖范围。自行创建或改名的房间不受影响，整个同步操作可以撤销。应用升级不会自动替换旧布局。

取消选择物体，在右侧「空间设置」编辑房间宽度和进深，或点击工具条中的「编辑房间尺寸」。宽度范围为 4–120 m，进深为 4–100 m，默认 12 × 10 m。按 Enter 或点击别处提交，每个字段修改可独立撤销、重做，并随备份保存。

缩小房间只改变边界，物体不会自动移动或缩放；墙外物体仍可从列表选择并移回。全景取景、相机裁剪与阴影范围随空间适配，大房间的阴影细节会相对较粗。

## 选择与摆放

点击左侧素材卡片添加物品，连续添加会寻找可用空位。点击场景物体或物体列表选择，可以移动、旋转、缩放、复制、锁定、隐藏、移除，也可以移到另一展厅。

程序建模物体可调整材质色彩；外部模型保留自身 PBR 材质。开启吸附后，移动步长为 0.25 m、旋转为 15°、缩放为 0.1 倍。一次操作柄拖动只产生一步历史；最多保留 80 步撤销历史，刷新后布局仍在，历史不再保留。

| 操作 | 输入 |
| --- | --- |
| 环绕 / 平移 / 缩放视角 | 鼠标左键 / 右键 / 滚轮 |
| 移动 / 旋转 / 缩放物体 | G / R / S，然后拖动三维操作柄 |
| 聚焦选中物体 | F |
| 恢复全景 | 取消选择后按 F |
| 复制 | Ctrl+D |
| 撤销 / 重做 | Ctrl+Z / Ctrl+Shift+Z |
| 删除物体 | Delete / Backspace |
| 取消选择 / 退出漫游 | Esc |

所有物体以底部为锚点，单位为米、Y 轴向上。地板位于 Y=0，展品与家具都是独立实例；移动展柜后需要分别调整柜内展品。

常用陈列高度：

| 陈列面 | Y 高度（m） |
| --- | --- |
| 方形展台顶面 | 1.00 |
| 圆形展台顶面 | 1.05 |
| 珠宝玻璃柜台绒面 | 0.92 |
| 收藏陈列柜层板 | 0.30 / 0.80 / 1.30 / 1.80 |
| 精品陈列桌台面 / 下层 | 0.86 / 0.25 |

把展品的 Y 位置设为相应高度即可贴合陈列面；不同模型还应观察实际摆放效果。珠宝玻璃柜台内部净高约 0.44 m。

## 装潢、地面与小珍藏

左侧「装潢」提供精品开店、绿意阅读、创作咖啡、玩趣收藏四套布置，每套添加六件独立物体，并设置配套地面。整套操作可以撤销。当前房间保留该套装的标记物体时，再次点击不会重复添加；需要更多家具时可单独添加或复制。

取消选择后，在右侧「脚下的质感」选择画廊原色、暖木地板、浅色水磨石或灰蓝石砖。选中扭蛋机，点击「免费扭一下」抽取六款小珍藏之一；收藏图鉴统计所有展厅中实际持有的扭蛋物件。

搭配清单、空位规则与图鉴行为见[装潢与收藏玩法](decor-workshop.md)。

## 导入模型

通过模型导入入口选择自包含 `.glb`，单文件最大 50 MiB。模型原文件保存到 IndexedDB，模型库卡片可以多次放置；各实例拥有独立的变换参数。

导入模型按最长边 1.2 m 归一化并居中贴地，随后可以调整尺寸。请在 Blender 等工具中导出 glTF 2.0 Binary，并把纹理和几何数据嵌入文件。导入约束与静态模型准备方法见 [GLB 素材接入](aigc-gallery.md)。

## 保存、备份与恢复

布局自动保存到当前浏览器的 LocalStorage，键名为 `model-space.project.v1`。模型原文件保存在 IndexedDB 数据库 `model-space-assets`。这些数据属于浏览器及站点 origin；换浏览器、换设备、换主机或端口时不会自动迁移。

点击「导出空间」获得 `.modelspace`，其中包含布局与全部导入模型原文件。完整备份大小上限为 200 MiB，约可容纳 150 MiB 原始模型，还需扣除布局开销；内置素材由对应版本应用随附。

通过「从备份恢复空间」选择文件。恢复前会完整校验项目结构、GLB 文件及引用关系，再为模型写入新的存储键。恢复会替换当前项目，可以在当前会话中撤销；操作前建议先导出当前空间。

损坏的已有存档不会被自动覆盖，界面会提示从完整备份恢复。未再引用的模型文件暂时保留，以支持撤销恢复；没有破坏性的自动清理。应用没有账号、云同步、模型上传接口或多人协作服务。

## 当前边界

- 需要支持 WebGL 且开启硬件加速的浏览器。桌面键鼠适合布展和漫游；小屏设备通过侧边按钮打开素材与属性面板，漫游没有触控摇杆。
- 暂不支持 `.blend`、`.fbx`、`.obj`、外部资源 `.gltf`，以及 Draco、Meshopt、KTX2 压缩。请转换为内嵌资源的普通 GLB。
- 骨骼模型以静态姿态展示，没有动画播放面板、动态试戴或实时皮肤变形。
- 展柜与展品彼此独立；目前没有自动父子绑定或物体分组。
- 漫游碰撞使用实际世界包围盒，属于保守的导航阻挡，不是逐三角形人体物理。更多细节见[漫游说明](immersive-gallery.md)。
- 房间上限为 30，每间最多 500 件物体，导入模型库最多 300 个资源；这些是数据校验上限，并不保证高密度场景在所有设备上流畅运行。
- 内置模型和纹理随应用提供，运行时不依赖素材站 CDN。本项目尚未提供 Service Worker 离线缓存；在线站点首次访问仍需要下载应用资源，本地静态服务可以在无互联网时运行。
